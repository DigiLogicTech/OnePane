# RC11 P0-AD — Exact human-approved Node execution scope

This increment creates a distinct consent path for explicitly initiated Node-local one-shot private TCP probes. It MUST NOT reuse the existing peer-connectivity transport grant as network execution authority.

Migration 0086 records one immutable execution permit per original human-issued instrument challenge (unique for life, including after revocation). The projectworkspace service grants it to an active human reviewer with a current Goal revision only when the Project/Goal/Workspace remains active and Level 5 configured, the instrument key, declared target, TLS pin and current private TCP approval are live, the original challenge remains unconsumed and matches its original signed-message encoding, and both directions of one paired Node remain confirmed. The permit stores bounded exact Project, Goal, Workspace, source, Node ID, enrolled pinned Node TLS fingerprint, original nonce and instrument public-key hashes, declared target/TLS pin and approval expiry. It contains no raw endpoint. Human revocation increments a revision and is auditable; old scopes cannot be rewritten or deleted.

The opt-in onepane-node-custody probe-and-witness command now REQUIRES an execution-permit file. It checks the exact Node identity and fingerprint, source, project, Goal, instrument identity, original challenge digest, target/TLS pin and chronology before any socket or local one-shot nonce reservation. Additional negative tests deny wrong Node, wrong public key, changed challenge/target/source/pin, stale or revoked-looking permit, and invalid revision.

IMPORTANT: the exported JSON is not server-signed; authentication depends on the independent human-approved transfer channel. Offline clients cannot detect server revocation after export. The permit cannot outlive the original short-lived challenge, and OnePane server acceptance must separately recheck live state. This stage adds no background scheduler, scanning, target discovery, physical device attestation, trusted vantage, incident vote, verified health or Level 5 host-remediation power.

Before calling this complete, add a human-only API and server-signed authenticated permit handoff (or equivalent online revocation verification), assess physical paired Node execution, then calibrated same-target evidence and reversible playbooks.
