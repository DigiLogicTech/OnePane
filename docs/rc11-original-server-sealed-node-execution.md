# RC11 — Human-controlled OnePane-origin-signed Node execution

This is a MANUAL local-first security research workflow. It is never enabled by default for Level 4 and does not install any background scanner, inference fallback, incident-automation or remediation worker.

Original approvals: the human configures a Level 5 Goal; issues an exact RFC1918 TCP4 permit (host, port, 100–1500 ms timeout), declared target and TLS pin, separately enrolls an instrument key, and issues its <=2-minute original v2 challenge. The human-only probe-plan export contains private endpoint metadata; retain it securely.

Bound human identity: the separate human operator Ed25519 private key signs a precise, versioned approval request for the original Project, Goal, issued challenge, paired Node and optimistic Goal revision (onepane-node-custody prepare-approval-request). The authenticated API derives the actual actor; it does not trust a principal ID supplied by the Node. The human-only grant API records an immutable digest of the operator public key. A key mismatch, Agent principal, unpaired Node or reused nonce is rejected.

Server-origin approval: the SAME authenticated reviewer obtains the one-shot grant and POSTs to /v1/projects/{projectID}/continuous-goals/{goalID}/node-probe-execution-permits/{permitID}/seal. The original live OnePane server uses its EXISTING local federation Ed25519 identity to sign a CURRENT active permit snapshot. No server key is generated by the endpoint. Protect the resulting signed server envelope as sensitive metadata.

Human signature: onepane-node-custody sign-execution-permit now REQUIRES the server-seal file, independently enrolled ORIGINAL OnePane PEM certificate, known server Node ID, independently pinned server SHA-256 fingerprint, operator private signing key, operator principal ID and a NEW private output path. It first verifies the OnePane origin cryptographically and refuses any unsigned raw-permit downgrade; it then signs exactly the original active approval. Human and server permit metadata must agree.

One shot on the paired Node: manually invoke onepane-node-custody probe-and-witness with original signed server envelope and independently pinned OnePane certificate/ID/fingerprint; separate human-signed permit and enrolled human public key; original challenge, private TCP plan and enrolled instrument private/public key; existing paired Node directory, Node ID and independently pinned Node certificate fingerprint; plus two fresh private outputs. It preflights all four software-key identities, original exact bounded plan and independently supplied original trusted approvals before opening at most one TCP4 socket. A crash or failed dial consumes the durable per-instrument-key nonce, with no automatic retry or discovery.

Historical review: onepane-node-custody verify-execution requires ORIGINAL server seal/pinned certificate, human signed permit/public key, Node custody witness/pinned certificate, instrument receipt/public key, challenge and private plan. It verifies signed software custody as of the original claimed observation; the older sign and verify commands cover smaller chains and NEVER authorise a new effect.

LIMITS: Four Ed25519 software identities are not TPM/TEE hardware attestation or proof of independent sensors, actual device identity, trustworthy network vantage, incident confidence, or runtime server revocation. Detached offline approvals cannot learn post-export revocation until short original challenge expiry. The human seal handler's live-state read and sign can race a concurrent revocation; existing server admission must revalidate current scope. No automatically promoted Goal health, internet scanning, remediation or host-command authority exists. Physical Node execution, Windows NTFS ACL and installed Windows/Ubuntu QA are outstanding.

Full security/code and low-RAM endurance review remain before release. Human-centred controllable/customisable UI/UX alignment must be the LAST workstream before an explicitly approved QA installer. Preserve installed models, Projects and user data.
